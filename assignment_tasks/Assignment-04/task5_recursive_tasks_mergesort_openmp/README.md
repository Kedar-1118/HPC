# task5_recursive_tasks_mergesort_openmp

- **Assignment**: Assignment-04
- **Task Description**: Divide-and-conquer parallel merge sort using OpenMP recursive tasks
- **Primary Library / API**: OpenMP
- **Primary Code File**: `recursive_tasks.cpp`

## 🚀 Compilation & Execution Guide

```bash
# Compile with G++ (C++17 with OpenMP support)
g++ -O3 -std=c++17 -fopenmp recursive_tasks.cpp -o recursive_tasks

# Set number of OpenMP threads and execute
export OMP_NUM_THREADS=4
./recursive_tasks
```
